# The Coding Zone — Official Website

> **Think Create Code**  
> Premier coding institute for Grade 9–12 & Diploma students in Belagavi (Belgaum), Karnataka.  
> Founded & Mentored by **Priyanka Desurkar** (B.E & M.Tech).

---

## 🌟 Overview

A modern, responsive, high-performance web application built with **React**, **Node.js**, and **Vite** reflecting the visual polish and user experience principles inspired by leading educational platforms (e.g., PW.live). All institute data, curriculum modules, certifications, and testimonials are accurately integrated from the official [launchpad.pdf](file:///c:/Users/prati/Music/project/launchpad%20.pdf).

---

## 🚀 Key Features

- **Sticky Navigation Bar:** Real-time section scroll tracking, mobile drawer, contact quick-links, and "Book Free Demo" CTA.
- **Hero Section:** Code-editor syntax window, dynamic animated tags, trust badges, and dual primary CTAs.
- **Flagship Learning Tracks:**
  - **Track 01:** Front End Development (*HTML5, CSS3, JavaScript, DOM, Netlify deployment*)
  - **Track 02:** Python & AI Programming (*Python OOP, Tkinter GUI, Data Science, Machine Learning, TensorFlow, Flask*)
- **15-Module Interactive Curriculum:** Tab-switched timeline with expandable module accordions detailing curriculum topics and hands-on coding activities.
- **About Founder & Center:** Highlighting founder credentials (**Priyanka Desurkar, B.E & M.Tech**), philosophy, core benefits (*Creativity, Logical Thinking, Confidence, Problem Solving*), and course inclusions.
- **Industry Certifications & Tools:** 4 skill credentials (*Front End Developer, Python Programmer, Data Scientist, AI Programmer*) and tech stack chips (*VS Code, Colab, Pandas, Flask, TensorFlow, etc.*).
- **Testimonials Carousel:** Multi-card carousel with touch and keyboard controls, featuring feedback from students and parents across Karnataka and Australia.
- **Direct Demo Booking & WhatsApp Integration:** Contact form with input validation and 1-click pre-filled WhatsApp demo reservation redirect.
- **Floating Contact CTAs:** Quick-access buttons for direct phone calls and instant WhatsApp conversation.

---

## 🛠️ Tech Stack

- **Frontend Library:** React 18
- **Build Tool:** Vite 5
- **Icons:** Lucide React
- **Styling:** Modular CSS with design token architecture (Typography, Spacing, Color tokens)
- **Intersection Observer:** `react-intersection-observer` for viewport triggers

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher)
- npm (v9 or higher)

### Setup & Run
```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Open in browser
http://localhost:3000
```

### Production Build
```bash
# Create optimized production build
npm run build

# Preview production build locally
npm run preview
```
